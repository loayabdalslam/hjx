HJX Language Specification v0.2

The complete syntax reference for HJX

📁 File Structure

Every .hjx file follows this block structure:

component <Name>       ← Component declaration
imports:              ← Optional: import other .hjx components
state:                 ← Reactive variables
computed:             ← Computed values (derived from state)
api:                   ← Optional: REST API endpoints
layout:                ← UI tree (indentation-based)
style:                 ← Natural language CSS or raw CSS
breakpoints:           ← Optional: custom media breakpoints
handlers:              ← Event logic
script:                ← Optional: server-side code

📝 State

state:
  count = 0                ← Number
  name = "John"            ← String
  active = true            ← Boolean
  items = ["a", "b"]       ← Array
  user = { name: "John" }  ← Object

🖼️ Layout

Basic Elements

SyntaxDescription

textInline text (<span>)
buttonButton element

view#id.class1.class2:ID + classes
text: "Hello {{name}}"Text interpolation
button (on click -> handler): "Label"Event binding
input (bind value <-> stateVar)Two-way binding

Control Flow

layout:
  if (isLoggedIn):
    text: "Welcome back!"

  for (item in items):
    view.row:
      text: "{{item}}"

🎨 Style (Natural Language CSS)

Write styles using human-readable descriptions:

style:
  .container:
    container          ← max-width: 1200px, margin: auto, padding
  .card:
    card               ← padding, background, border-radius, shadow
  .button:
    button primary     ← padding, background, color, border, cursor
  .input-field:
    input field        ← padding, border, font-size, width

⚡ Handlers (Event Logic)

handlers:
  increment:
    set count = count + 1
    log "Incremented to {{count}}"
  
  decrement:
    set count = count - 1
  
  reset:
    set count = 0
    log "Counter reset"

Available Commands

CommandDescription
set x = valueSet state variable
set x = [...x, new]Add to array
set x = x.filter(...)Filter array
fetch handler -> resultAPI call
log "message"Console log

🔌 API Integration

api:
  GET /api/todos -> fetchTodos:
    query:
      page = 1
      limit = 10

  POST /api/todos -> createTodo:
    body:
      text = string
      done = boolean

  DELETE /api/todos/:id -> deleteTodo:
    params:
      id = number
