🚀 Quick Start

1. Install & Build

git clone https://github.com/loayabdalslam/hjx.git
cd hjx
npm install
npm run build

2. Create from Plain English

node dist/cli.js flow "create a counter component"
# Output: Full HJX code

3. Build to Web Project

node dist/cli.js build myfile.hjx --out dist-output
# Creates: index.html + app.js + app.css + runtime.js

4. Build to React

node dist/cli.js build myfile.hjx --target react --out dist-react
# Creates: Component.tsx + Component.module.css

5. Start Dev Server

node dist/cli.js dev examples/01-beginner-counter.hjx --port 5172
# Open http://localhost:5172

🧠 NLP Flow-State Engine

How It Works

The Flow-State Engine converts plain English descriptions directly into HJX code. You can also mix English with code for a seamless development experience.
