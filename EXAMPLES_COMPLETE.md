## 🔧 Customization

### Modify an Example
```bash
# Edit the file
code examples/01-beginner-counter.hjx

# Build and run
npm run build
npm run example:counter
```

### Create New Example
```bash
# Create new file
touch examples/06-custom-name.hjx

# Add your code and run
npm run build
node dist/cli.js dev examples/06-custom-name.hjx --out dist-custom --port 5174
```

### Generate from English
```bash
node dist/cli.js flow "Create a counter that increments by 5"
```
