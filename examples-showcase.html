📚 Getting Started

These examples demonstrate HJX's capabilities across different complexity levels. Each example is production-ready and showcases best practices for building interactive applications.

Build & Run Examples

# Build the compiler npm run build # Run examples server npm run examples:dev # Build specific example node dist/cli.js build examples/01-beginner-counter.hjx --out dist-counter --target react # Generate from natural language node dist/cli.js flow "Create a counter that increments by 5"
